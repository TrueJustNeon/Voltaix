About Voltaix

Voltaix is a technology and energy-focused mod for Minecraft 1.21.1 on NeoForge. It adds new ores, materials, and machines to automate your world.

What you will find here

  • Installation instructions for setting up the mod
  • A catalog of blocks and items with IDs and descriptions
  • Useful debug commands for testing and development

Installation Guide

Requirements

  • Minecraft 1.21.1
  • NeoForge 21.1.x
  • Java 21

Steps

  1. Install NeoForge 1.21.1
  2. Visit Modrinth.com and search for Voltaix
  3. Download voltaix-x.x.x.jar
  4. Place the file in your /mods folder
  5. Launch the game and the mod will be ready to use
