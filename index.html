About Voltaix

Voltaix is a technology and energy-focused mod for Minecraft 1.21.1 on NeoForge. It adds new ores, materials, and machines to automate your world.

Core Features

  • New ore generation: Voltaix Ore
  • Custom energy system: Coal Generator & Solar Panels
  • Automation machines
  • Upgraded tools and circuits

Installation Guide

Requirements

  • Minecraft 1.21.1
  • NeoForge 21.1.x
  • Java 21

Steps

  1. Install NeoForge 1.21.1
  2. Go to Modrinth.com and search the mod.
  3. Download voltaix-x.x.x.jar
  4. Place the file in your /mods folder
  5. Launch the game and the mod should be ready for use.
